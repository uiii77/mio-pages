# Mio 🌙

**A world of your own.**

Mio 是一个以 AI 角色互动为核心的个人数字空间。它将角色对话、记忆、日程与日常记录等功能放在同一个网页应用里，希望让虚拟角色不只停留在一次聊天中，而是能够与自己的故事和生活产生更多联系。

这是一个持续开发中的个人项目。你可以打开公开网页体验现有功能；部分能力仍在调整，实际体验也取决于浏览器和所配置的外部服务。

**[🌐 打开 Mio](https://uiii77.github.io/mio-pages/)**

## ✨ 可以做什么？

- **AI 角色对话：** 创建和配置角色，管理对话、聊天设置与不同的 AI 服务。
- **记忆与关系：** 为角色互动提供持续的记忆、关系和上下文管理。
- **日程与提醒：** 使用日历、提醒和个人日程等工具组织日常活动。
- **创作与互动：** 探索日记、阅读、音乐、角色空间及其他互动模块。
- **个性化界面：** 调整应用外观和部分交互设置，让空间更符合自己的喜好。

> 不同功能的完成度和使用条件可能不同；涉及 AI、语音、在线媒体等外部能力时，通常需要自行配置相应服务。

## 🚀 如何体验？

### 在线使用

1. 访问 **[Mio 网页版](https://uiii77.github.io/mio-pages/)**。
2. 根据页面引导进行初始设置。
3. 如需 AI 对话或其他在线服务，在应用内配置自己有权使用的服务及 API 信息。

不需要下载或安装开发工具。

### 添加到手机主屏幕

Mio 采用 PWA（渐进式网页应用）相关技术。在支持的浏览器中，可以通过“添加到主屏幕”或“安装应用”使用；具体入口因设备和浏览器而异。

部分页面资源和本地记录可在离线时访问，但 **AI 请求和其他在线服务仍需要网络及有效的服务配置**。

## 🔐 数据与隐私

Mio 采用 **local-first（本地优先）** 的设计思路，部分个人数据使用浏览器的 IndexedDB 等本地存储机制保存。

使用前请留意：

- **本地不等于自动同步：** 不同设备、浏览器或网站地址的数据通常不会自动合并。
- **清除浏览器数据可能造成记录丢失：** 如应用提供导出和备份功能，建议在重要操作前自行备份。
- **外部服务会处理发送给它们的请求：** 使用 AI、语音或其他在线功能前，请了解相应服务的隐私规则与费用。
- **不要共享 API 密钥：** 请勿将密钥、个人对话或备份文件发布到公开位置。

本项目不是云端账号同步服务，也不保证所有功能都能完全离线运行。

## 🧩 关于这个仓库

本仓库 **`mio-pages`** 用于公开展示和发布 Mio 的网页运行版本。

```text
mio-pages/
├── .github/workflows/   # GitHub Pages 部署流程
└── site/                # 公开网页的运行文件
    ├── index.html       # 页面入口
    ├── js/              # 前端脚本
    ├── css/             # 页面样式
    ├── assets/          # 公共静态资源
    ├── manifest.json    # PWA 配置
    └── sw.js            # Service Worker
```

Mio 的日常开发、构建、测试和内部文档在独立的私人仓库中维护。这里保留的是发布所需的公开前端文件，**并不是完整的开发源仓库**，因此不提供从本仓库构建整个项目的步骤。

这个公开版本通过 GitHub Actions 部署到 GitHub Pages；发布内容会随着经过验证的新版本更新。

## 🛠️ 使用到的技术

- **前端：** HTML、CSS、JavaScript
